# EC032 Zinc-Air Battery — F1b SOC-Thermal

## Key Physics
- Zn + 0.5 O2 -> ZnO; E^0 = 1.65 V
- R(T): Arrhenius with E_a = 30 kJ/mol (alkaline KOH electrolyte)
- dOCV/dT = -0.0004 V/K (negative: entropy decreases on discharge)
- Q = I^2*R(T) + I*T*dOCV/dT

## References

- Parker et al. (2017). Science 356(6345), 415-418.
