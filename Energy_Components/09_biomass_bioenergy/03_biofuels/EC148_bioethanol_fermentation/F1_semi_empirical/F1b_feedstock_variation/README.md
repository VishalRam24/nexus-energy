# EC148 Bioethanol Fermentation — F1b Feedstock Variation

## Key Physics
- **Stoichiometry**: Gay-Lussac: 0.511 kg EtOH/kg glucose
- **Moisture-LHV**: `LHV_eff = LHV_dry*(1-M) - h_fg*M`
- **Temperature kinetics**: Arrhenius peak at 30-35°C; sigmoidal inactivation above T_opt
- **Product inhibition**: Andrews-type `f = C_50 / (C_50 + C_EtOH)`
- **Pretreatment**: Lignocellulosic feedstocks have lower effective sugar conversion (0.68-0.80)
