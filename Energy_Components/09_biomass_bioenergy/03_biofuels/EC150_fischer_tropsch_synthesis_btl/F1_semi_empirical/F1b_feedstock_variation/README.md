# EC150 Fischer-Tropsch Synthesis (BtL) — F1b Feedstock Variation

## Key Physics
- **Moisture-LHV coupling**: `LHV_eff = LHV_dry*(1-M) - h_fg*M`
- **ASF distribution**: `W_n = n*(1-α)²*α^(n-1)` — products from CH4 to wax
- **Alpha (chain growth)**: Decreases with T; lower at off-ratio H2/CO
- **H2/CO from feedstock**: Moisture shifts ratio via water-gas shift (more H2)
- **CO conversion**: Bell-shaped around T_ref=230°C and H2/CO=2.0
