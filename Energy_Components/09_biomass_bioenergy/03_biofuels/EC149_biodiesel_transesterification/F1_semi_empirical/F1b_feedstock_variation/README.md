# EC149 Biodiesel Transesterification — F1b Feedstock Variation

## Key Physics
- **Stoichiometry**: 1 mol triglyceride + 3 mol MeOH → 3 mol FAME + glycerol; ~1.02 mass factor
- **Moisture-LHV**: `LHV_eff = LHV_dry*(1-M) - h_fg*M`
- **Temperature**: Arrhenius peak at 55-65°C; MeOH volatilization above T_opt
- **FFA penalty**: Each 1% FFA above 1% reduces yield by 2% (saponification competition)
